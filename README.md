# Kitchen Autoposter - LangGraph Telegram System

Система автопостинга для Telegram-канала по теме «реставрация кухонь».

## Архитектура

- **Poster**: генерация черновика (поиск + текст + картинка) → отправка на одобрение админу
- **Manager**: управление расписанием и одобрение (только в одном чате от одного user_id)
- **Moderator**: фильтрация комментариев (удаление спама/мата/рекламы)
- **Responder**: короткие ответы на пропущенные комментарии

Порядок комментариев: входящее → Moderator → (если ок) → Responder.

## Быстрый старт

1. Скопируй `.env.example` в `.env` и заполни все ключи.
2. Подними Postgres:
   ```bash
   docker compose up -d postgres
   ```
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Инициализируй схему (выполняется автоматически при старте).
5. Запуск:
   ```bash
   python -m app.main
   ```

Бот должен быть админом в канале и в discussion group (для удаления сообщений).

## Переменные окружения

Смотри `.env.example`.

## Ограничения текущей реализации

- Генерация картинок: сейчас ставится placeholder. Для полноценной работы с `MODEL_IMAGE` (flux и т.п.) нужно подключить актуальный image endpoint OpenRouter (см. их документацию на момент деплоя).
- Web search в Poster: реализован через промпт к модели. Для настоящего `openrouter:web_search` tool — bind tool в LangChain, когда модель его поддерживает.
- Manager: распознавание времени для смены расписания упрощено — в продакшене лучше парсить HH:MM regex'ом или отдельным шагом.
- Checkpointer LangGraph в Postgres не подключён по умолчанию (состояние короткое). Можно добавить `langgraph-checkpoint-postgres` при необходимости.

## Запуск на VPS

Рекомендуется systemd unit или docker для основного процесса. Бот должен иметь права админа в discussion group для удаления сообщений.
