# Kitchen Autoposter — LangGraph Telegram System

Автопостинг и управление Telegram-каналом про реставрацию кухонь.

## Что умеет

- **Автопостинг по расписанию** (по московскому времени) — генерирует и сразу публикует.
- **Внеплановые посты** — по запросу админа (сейчас или на точное время). Можно прислать свои фото или задать тему.
- **Два режима генерации**:
  - Обычный Poster — сам выбирает тему из рубрик, помнит последние 10 постов.
  - Custom Poster — когда есть фото или явно задана тема. Смотрит фото, пишет строго по запросу.
- **Одобрение** внеплановых и ручных черновиков в Manager-чате.
- **Модерация комментариев** — удаляет мат, спам, рекламу. На нормальные отвечает коротко.
- Управление только из одного чата и только от разрешённых user_id (можно несколько через запятую).

## Архитектура

- Poster / Custom Poster — генерация текста и картинок
- Manager — расписание, внеплановые, подтверждения
- Moderator → Responder — обработка комментариев
- APScheduler (опрос базы каждые 30 сек)
- Postgres — расписание, черновики, посты, внеплановые

## Быстрый старт

1. Скопируй `.env.example` → `.env` и заполни.
2. Postgres:
   ```bash
   docker compose up -d postgres
   ```
3. Зависимости:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. Запуск:
   ```bash
   python -m app.main
   ```

Бот должен быть админом в канале и в discussion-группе.

## Управление (в Manager-чате)

- `расписание` — показать слоты и внеплановые
- `измени расписание на 9:00, 18:00` → `да`
- `внеплановый пост` / `опубликуй пост про ...` (+ фото по желанию)
- `да` — подтвердить
- `отмени внеплановый`

## Переменные

Смотри `.env.example`.  
`MANAGER_USER_ID` — один или несколько ID через запятую.
